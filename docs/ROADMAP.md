# Roadmap · Cron Visualizer

- [x] Parser e validação de cron clássico com cinco campos.
- [x] Listas, intervalos, passos e nomes de meses/dias.
- [x] Semântica OR entre dia do mês e dia da semana.
- [x] Simulação de execuções, explicação e presets.
- [x] Interface responsiva, cópia e data inicial.
