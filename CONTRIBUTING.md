# Contribuindo para o Cron Visualizer

Obrigado por contribuir com o LAB//ABERTO.

1. Use Node.js 20+ e crie uma branch para a alteração.
2. Execute `npm run check` e `npm test`.
3. Inclua testes para alterações de comportamento.
4. Preserve a semântica cron de cinco campos, inclusive o **OU** entre dia do mês e dia da semana quando ambos forem restritos.
5. Prefira JavaScript legível, sem dependências ou serviços externos.
6. Não adicione coleta de dados, execução de comandos ou acesso a crontabs sem discussão.
7. Verifique navegação por teclado e contraste em mudanças de UI.

Use commits claros: `feat:`, `fix:`, `docs:`, `test:`.

Para problemas de segurança, consulte [SECURITY.md](SECURITY.md).
